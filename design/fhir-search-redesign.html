Batch / Transaction

Send several actions to the server in one request.

How will the actions run?

Decided by the file — Bundle.type in the uploaded JSON, not a setting you pick here.

Batchfrom fileBundle.type = batch Each action runs on its own — some can succeed while others fail. You get a status per action.
Transactionfrom fileBundle.type = transaction All-or-nothing — if any action fails, the server rolls back the entire set and nothing is saved.
